# TVAutoPlayer V1.5.0

V1.5.0 增加多个每日时间段的独立图片/视频播放列表。规则支持跨午夜、总开关、单条停用、冲突拦截和约 30 秒边界检查；未覆盖时段继续使用原默认列表。

## 主要变化

- 新增电视遥控器可操作的时间段总览与编辑页。
- 每条规则可配置开始/结束时间、启用状态和独立混合媒体列表。
- 开始时间包含、结束时间不包含；结束早于开始表示跨午夜。
- 启用规则不能重叠，相邻时间段允许保存。
- 播放中只在有效规则来源变化时重建队列，普通检查不打断当前媒体。
- 仅有未来时间段且默认列表为空时，开机可进入等待状态并到点播放。
- V1.4.0 及更早配置直接兼容，升级后时间段功能默认关闭。
- Android 版本升级为 `versionCode=9`、`versionName=1.5.0`。

## 安装

下载 `TVAutoPlayer-v1.5.0-debug.apk` 后侧载，或执行：

```powershell
adb install -r .\TVAutoPlayer-v1.5.0-debug.apk
```

相同 Debug 签名可覆盖安装并保留设置。不同签名需要卸载旧版，会清除应用设置但不会删除媒体。

## 验证范围

- 中英文资源一致性与中文 UI 硬编码检查。
- 时间匹配、跨午夜、冲突检测、解析优先级、配置容错和旧配置兼容单元测试。
- Android Lint、Debug APK 构建、包清单、权限、ZIP 对齐、v1/v2 签名和 SHA-256。

真实电视上的 U 盘索引、遥控器焦点、边界时间精度、厂商开机限制和长时间循环仍需目标设备验收。
